# Maverick

Broken Arrow 第三方桌面数据工具：自动识别对局并批量查询敌我玩家数据。

## 下载

到 [Releases](https://github.com/Zggggg123/BA-Maverick/releases) 页面下载最新的 `maverick-Setup-x.y.z.exe` 安装包（Windows x64）。

- 安装时可自定义安装目录
- 应用内置自动更新（检测到新版本会提示）

## 使用说明

1. 从 Steam 启动 Broken Arrow 并进入对局
2. Maverick 自动从游戏日志识别当前对局的 10 名玩家
3. 在「对局情报」页查看敌我玩家数据，点击任意玩家可打开详情页签
4. 「数据」页可查看任意玩家的生涯画像、对局记录与好友列表
