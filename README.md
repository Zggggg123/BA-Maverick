# Maverick

Broken Arrow 第三方桌面数据工具：自动识别当前对局并批量查询敌我玩家数据。

> **合规声明（请先读这一段）**
>
> - 本工具是**只读辅助**：仅读取本地游戏日志与 Steam 配置文件，通过 BATrace 公开 API 查询数据
> - **不注入**游戏进程、**不读内存**、**不修改游戏文件**、**不监听游戏端口**、**不向游戏端发送任何指令**
> - **不提供任何游戏内优势或自动化辅助功能**（无 auto-cheat、无自动瞄准/自动操作、**不是游戏内 Overlay**）
> - 非官方工具：与 Broken Arrow 开发商、与 BATrace 运营方**均无关联**；地图名 / 单位名等游戏内容版权归其各自所有者

## 下载

到 [Releases](https://github.com/Zggggg123/BA-Maverick/releases) 页面下载最新的  
`Maverick-x.y.z-win.zip`（Windows x64 便携版，例如 `Maverick-0.3.0-win.zip`）。

- **免安装**：解压到任意有写权限的目录，双击 `Maverick.exe` 即可  
  （❌ 别解压进 `Program Files`，那里没有写权限，程序日志会降级）
- **升级**：下载新版 zip **解压到新目录**、把旧的删掉即可，**设置不会丢**（设置存在 `%APPDATA%\Maverick`，
  跟解压到哪儿无关；所以「覆盖解压到原目录」不是保设置的手段）
- ⚠️ **没有安装包**，程序也**不会自己下载安装**新版本 —— 它只在设置页提示「发现新版本」，
  点一下帮你打开这个下载页，**解压替换仍然要你手动做**
  （⚠️ `0.2.5` 起才有这个提示；更早的版本不会提示，得自己回来看看）

## 使用说明

1. 从 Steam 启动 Broken Arrow 并进入对局（工具开局前打开、对局中途打开都行）
2. Maverick 自动从游戏日志识别当前对局的 10 名玩家
3. 在「对局情报」页查看敌我玩家数据，点击任意玩家可打开详情页签
4. 「数据」页可查看任意玩家的生涯画像、对局记录与最近队友

## 系统要求

- **Windows 10 1809+ / Windows 11**，**64 位（x64）** —— 没有 32 位版本
- 不需要管理员权限
- 需要已安装 Steam 并**登录过 Broken Arrow**（否则既没有账号信息也没有游戏日志）
- 需要网络（玩家数据来自 `dash.batrace.top`；**跟随系统代理**，被公司网络 / 防火墙拦掉就查不到数据）

## 看不到数据？

- 在「设置 → 文件目录」里可以**手动指定 Steam 安装目录或游戏日志目录**，改完立即生效
- 报障时请把「设置 → 文件目录」里那个**程序日志目录**下的 `main.log` 发过来
- 「对局情报」一直是空的，最常见原因是：游戏没在跑，或者日志目录指错了
